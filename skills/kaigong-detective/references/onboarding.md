# 第一次连接元宝搜索

## 对用户怎样说

首次没有可用连接时，用一段短说明带用户走完，不只抛异常或索要一串密钥：

> 还差一步连接元宝搜索。连上后，我就能查相似项目，给你带出处的问题和推荐。
>
> 先到[腾讯云元宝搜索控制台](https://console.cloud.tencent.com/wsapi/index)开通服务，再按[官方指引创建服务 API KEY](https://cloud.tencent.com/document/product/1806/130615#21242563-b79b-4db5-962a-12a9a39ebc16)。拿到后，在你自己的终端运行下面的配置命令，粘贴时不会显示密钥，也不需要发到聊天。
>
> 这个命令会保存本机配置，并做一次真实搜索测试，可能消耗1次API额度。暂时不配也可以先聊需求，搜索部分等连接好再继续。

随后给出`python3 "当前技能绝对路径/scripts/connect.py" configure --test`，不要把示例路径原样留给用户，不用展示一堆SDK或HTTP细节。

官方 API KEY 创建指引包含登录注册、开通服务、创建服务密钥步骤；控制台版本、额度和计费以用户当前账号为准。不要承诺安装技能附赠6000次、永远免费或自动开通服务。服务API KEY只在创建时明文返回，用户在本机保存，不把它写入聊天、报告、截图、源码或分发包。

## 已有配置时复用

优先判断已有连接，而不是见到首次调用就要求重新给Key。

1. 本会话已有真实元宝调用成功，继续使用；不需要再次测试同一个连接。
2. 远端元宝MCP可能已经配置密钥；本地CLI缺Key不等于MCP不可用。用第一条针对用户目标的真实MCP查询验证，成功就不另收本机凭据。
3. 本地CLI用`connect.py status`读取脱敏元数据。`configured=true`不是`connected=true`。第一条实际调查请求成功即可确认连通，避免额外测试。

向导配置后，本技能CLI自动从环境变量或`~/.config/yuanbao-search/.env`读取。环境变量优先；保存文件不会改变其他独立MCP服务器的配置。原有MCP配置失效时，可直接使用这个已配置的CLI调查，不重复用同一失败配置重试。

## 本机隐藏输入向导

只需Python3标准库：

```bash
python3 "<技能目录>/scripts/connect.py" status
python3 "<技能目录>/scripts/connect.py" configure
python3 "<技能目录>/scripts/connect.py" test
```

也可以将保存与测试合为`configure --test`。configure默认复用已有有效配置；用户明确要替换文件里的旧Key时才用`configure --replace`，环境变量存在时须在原环境变量管理处更新。只有用户在自己的交互终端隐藏输入，不把Key作为命令行实参，也不用普通read/input回显输入；无法安全隐藏输入时取消，留待用户的终端。

本机文件原有其他配置和注释保留，新Key原子写入，POSIX权限0600。不覆盖符号链接；此时沿用户原有管理方式配置。用户直接回车跳过时不创建空文件，不联网。没有Key/本机文件无法读取不算API调用，不消耗调查目录的尝试预算。

## 连接状态与友好恢复

| 状态 | 用户看到的说明与下一步 |
|---|---|
| 缺少本机Key | 先检查是否已有可用MCP；没有时给控制台、创建指引和隐藏输入命令 |
| 已找到本机配置 | 无需重新提供Key；第一条目标查询验证，或显式运行一次test |
| 文件不可读或格式有误 | 指向本机文件权限/编码或环境变量配置，不输出文件内容或密钥 |
| HTTP401/403、认证失败 | Key可能无效、过期或权限不符，检查服务API KEY与账号服务；不自动重复相同请求 |
| 账号资源/服务错误 | 检查控制台是否已开通服务与账号资源；不能一概说Key错误 |
| 额度或限频 | 引导看控制台额度、频率或服务提示；不直接让用户购买，限频可稍后重试 |
| 网络/代理故障 | 检查网络、代理或服务状态；不把它误说为Key无效 |
| 成功 | 明确“元宝搜索已连通”，保留RequestId与时间；回到原调查节点 |

test最多一次请求、不自动重试，不把网页结果全部打印给用户。HTTP成功但响应结构/RequestId不正确，不能报连通成功。空结果仍可能已连通，只说明本次没有返回网页，不判定目标不存在。

## 接入前后保持任务边界

用户暂不配置或调用失败时，保存需求树，继续不依赖外部证据的澄清。说明尚未使用搜索，不伪造来源，不把普通判断标成搜索后提问，也不绕过check-start。配置完成后从待查问题继续，不让用户重答整轮。

连接测试是技术检查，不是用户目标的发现—追查链。没有两次目标相关的真实请求、原文问答与共同理解确认，仍不能宣布可以制作目标项目。首次接入不自动购买额度、升级套餐、安装候选、部署或发送外部消息。
